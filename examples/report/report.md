# Summary

This report reviews three envelope options for the tower against the project's thermal
performance targets. **Option C** meets the targets with the lowest peak cooling load.

# Method

The analysis used a dynamic thermal model of a typical residential floor.

## Assumptions

- Weather file: Melbourne reference year.
- Occupancy and internal gains to the project brief.
- Glazing performance from manufacturer data.

# Results

| Option | Glazing | Peak cooling (W/m²) | Meets target |
|--------|---------|--------------------:|:------------:|
| A      | Double, clear   | 68 | No  |
| B      | Double, low-e   | 49 | No  |
| C      | Double, low-e, external shading | 34 | Yes |

![Peak solar heat gain for options A, B and C](figures/heat-gain.svg)

# Recommendations

1. Adopt option C for the north and west facades.
2. Confirm shading geometry with the architect before design development.
